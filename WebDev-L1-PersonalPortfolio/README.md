# Personal Portfolio Website

## About the Project

This is a responsive personal portfolio website developed using HTML5 and CSS3. It showcases personal information, technical skills, projects, and contact details in a clean and modern design.

The website serves as a digital résumé to present my skills and projects to recruiters and potential employers.

## Features

* **Home Section:** Introduces the developer with a name, role, and avatar.
* **About Me:** Provides information about the developer's background and interests.
* **Skills Section:** Displays technical skills in a visual card layout.
* **Projects Section:** Showcases projects with descriptions, technology tags, and GitHub links.
* **Contact Section:** Displays email, GitHub, and LinkedIn details.
* **Smooth Navigation:** Enables smooth scrolling between website sections.
* **Responsive Design:** Adapts to desktop, tablet, and mobile screens.
* **Modern UI:** Uses a dark theme with blue accents and consistent typography.

## Technologies Used

* HTML5
* CSS3
* Google Fonts — Poppins

## Getting Started

### Prerequisites

You need a web browser and a code editor such as Visual Studio Code.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/your-repository.git
   ```

2. Navigate to the project directory:

   ```bash
   cd personal-portfolio
   ```

3. Open `index.html` in your browser.

   Alternatively, open the project in Visual Studio Code and use the Live Server extension.

## Customization

To personalize the portfolio:

1. Replace the placeholder name and role with your details.
2. Update the About Me section with your background and interests.
3. Modify the skills section to reflect your technical skills.
4. Add your actual project descriptions and GitHub repository URLs.
5. Replace the placeholder email and social profile links.
6. Customize the avatar and colors if needed.
