# PLAYIT — Game Store Landing Page

A responsive landing page for **PLAYIT**, a fictional digital game storefront. Built for the Oasis Infobyte Web Development & Designing internship, Level 1 Task 1.

## Features

- Sticky navigation with mobile menu
- Hero section with clear calls to action
- Trending game cards with prices, ratings, and discount labels
- Browse-by-category section
- Special deals banner
- About section and newsletter form mockup
- Footer with placeholder social, support, and contact links
- Responsive layout using CSS Grid, Flexbox, and media queries
- Consistent dark palette with purple accents and accessible semantic markup

## Tech stack

- HTML5
- CSS3
- Tiny inline JavaScript enhancement for the mobile navigation
- Google Fonts and remote Unsplash images

> The internship task says JavaScript is not required. The page layout and styling are HTML/CSS; the small optional script only opens and closes the mobile navigation. Remove the final `<script>` block from `index.html` if you want a strictly HTML/CSS-only submission.

## Run locally

1. Download or clone this repository.
2. Open `index.html` in your browser.

No build tools or package installation are required.

## Notes

- PLAYIT is a fictional store concept. Game names, prices, ratings, discount labels, contact details, and social links are placeholders for a visual demo.
- Images are loaded from Unsplash and Google Fonts from Google Fonts, so an internet connection is needed for those external assets.
- The newsletter form is a visual mockup and does not submit data to a backend.
- This is a landing page, not a functioning checkout or purchasing system.

## Suggested demo walkthrough

1. Start with a 2-second title card showing your full name, assigned track, and task title.
2. Show the desktop landing page and scroll through the hero, trending games, categories, sale banner, and footer.
3. Resize the browser to a mobile width and demonstrate the responsive layout and mobile navigation.
4. End on the PLAYIT brand/footer.
